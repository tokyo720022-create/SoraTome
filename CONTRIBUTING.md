# Contributing to Tsuzuki

Thanks for your interest! The project is at a very early stage, so please open an issue to discuss larger changes before starting work.

## Ground rules

- Be respectful and constructive.
- Keep pull requests small and focused.
- Follow the Kotlin coding conventions and keep modules decoupled (see `docs/ARCHITECTURE.md`).

## Content policy for contributions

This project is a neutral reader. To keep it that way, we do **not** accept:

- built-in sources or default repositories for third-party sites
- links to, or listings of, third-party plugin repositories in the code, docs, issues, or discussions
- code that bypasses DRM, paywalls, or login walls

Sample and test plugins must use only content you have the right to use (your own, public domain, or openly licensed).

## Reporting issues

Please include your device, Android version, app version, and steps to reproduce. Don't include links to infringing material.
