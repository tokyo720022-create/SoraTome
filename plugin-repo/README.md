# SoraTome test repository

A small plugin repository for testing SoraTome's plugin install and update screens. It lists one plugin that reads MangaDex through MangaDex's public API.

SoraTome does **not** include this repository by default. To use it, open SoraTome > Profile > Settings > Browse > **Add repository** and paste:

```
https://raw.githubusercontent.com/tokyo720022-create/SoraTome/main/plugin-repo/index.json
```

See [docs/PLUGIN_REPOSITORY.md](../docs/PLUGIN_REPOSITORY.md) for the repository format.
